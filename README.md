# 🖼️ Image Watermarker (Python)

A simple Python application that adds customizable text watermarks to images using the Pillow library.

## 🚀 Features

- Add custom text watermark
- Supports PNG and JPG images
- Saves the watermarked image automatically
- Beginner-friendly Python project

## 🛠️ Technologies Used

- Python
- Pillow (PIL)

## 📂 Project Structure

## 📦 Installation

```bash
pip install -r requirements.txt
```

## ▶️ Run

```bash
python main.py
```
